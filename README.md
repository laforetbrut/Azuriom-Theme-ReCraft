# Theme ReCraft for Azuriom

![License](https://img.shields.io/badge/license-All%20Rights%20Reserved-red) ![Version](https://img.shields.io/badge/version-1.0.0-blue)

**[EN]** Modern purple/black/white Azuriom theme with full homepage, server status, Discord widget and advanced configuration.
**[FR]** Thème Azuriom moderne violet/noir/blanc avec page d'accueil complète, statut serveur, widget Discord et configuration avancée.

---

## 🇺🇸 English (US)

### Features
- **Modern Design**: Dark mode with purple accents, glassmorphism effects, and glow effects.
- **Full Homepage**: Hero section, features grid, stats counters, news, staff section, Discord widget, and CTA.
- **Server Status**: Live player count via API, server IP copy button, Minecraft sign-style card.
- **Highly Configurable**: 200+ settings configurable from the Admin Panel (colors, fonts, animations, sections order, etc.).
- **Responsive**: Fully compatible with mobile and tablet devices.
- **Bilingual**: Fully translated in English and French.
- **Custom Error Pages**: Styled 403, 404, 500, and 503 pages with particles and animations.
- **Scroll Animations**: Fade-up effects with configurable speed.

### Sections

All homepage sections can be reordered, enabled, or disabled from the Admin Panel:

| Section | Description |
|---------|-------------|
| **Hero** | Full-screen banner with background, title, subtitle, CTA buttons, particles, and server IP card |
| **Features** | Up to 6 feature cards with Bootstrap icons (1-4 columns) |
| **Stats** | Up to 4 stat counters (manual or API-based: online players) |
| **News** | Latest blog posts with images, dates, and excerpts |
| **Staff** | Up to 12 team members with avatars and roles |
| **Discord** | Discord widget with invite link and member count |
| **CTA** | Call-to-action banner with custom background and buttons |

### Customization

All configuration is done from the Azuriom Admin Panel. Key options:

- **Colors**: Primary, accent, background, card, border, text colors
- **Typography**: Font family, Minecraft font for headings
- **Navbar**: Style (glass), height, sticky, shadow, logo size
- **Hero**: Background image, logo, particles (mixed colors), overlay, buttons, server IP display
- **Sections**: Enable/disable each section, set order, customize titles/subtitles
- **Footer**: Description, social links (Discord, Twitter, YouTube, Instagram, TikTok, GitHub, Twitch), legal links
- **Advanced**: Custom CSS, JS, and head code injection

### Installation

1. Download the `recraft` folder.
2. Upload it to the `themes/` directory of your Azuriom installation.
3. Go to Admin Dashboard -> Appearance -> Themes.
4. Enable **ReCraft**.
5. Configure the theme from the settings panel.

### Requirements
- Azuriom API 1.2.0+

## 🇫🇷 Français (FR)

### Fonctionnalités
- **Design Moderne** : Mode sombre avec accents violets, effets glassmorphism et glow.
- **Page d'Accueil Complète** : Section hero, grille de fonctionnalités, compteurs stats, actualités, équipe, widget Discord et CTA.
- **Statut Serveur** : Joueurs en ligne via API, bouton copie IP, carte style panneau Minecraft.
- **Hautement Configurable** : 200+ paramètres configurables depuis le Panneau Admin (couleurs, polices, animations, ordre des sections, etc.).
- **Responsive** : Entièrement compatible mobile et tablette.
- **Bilingue** : Entièrement traduit en Français et Anglais.
- **Pages d'Erreur Personnalisées** : Pages 403, 404, 500 et 503 stylisées avec particules et animations.
- **Animations au Scroll** : Effets fade-up avec vitesse configurable.

### Sections

Toutes les sections de la page d'accueil peuvent être réordonnées, activées ou désactivées depuis le Panneau Admin :

| Section | Description |
|---------|-------------|
| **Hero** | Bannière plein écran avec fond, titre, sous-titre, boutons CTA, particules et carte IP serveur |
| **Fonctionnalités** | Jusqu'à 6 cartes avec icônes Bootstrap (1-4 colonnes) |
| **Stats** | Jusqu'à 4 compteurs (manuels ou API : joueurs en ligne) |
| **Actualités** | Derniers articles du blog avec images, dates et extraits |
| **Équipe** | Jusqu'à 12 membres avec avatars et rôles |
| **Discord** | Widget Discord avec lien d'invitation et compteur de membres |
| **CTA** | Bannière call-to-action avec fond personnalisé et boutons |

### Personnalisation

Toute la configuration se fait depuis le Panneau Admin Azuriom. Options principales :

- **Couleurs** : Primaire, accent, fond, carte, bordure, texte
- **Typographie** : Police, police Minecraft pour les titres
- **Navbar** : Style (glass), hauteur, sticky, ombre, taille du logo
- **Hero** : Image de fond, logo, particules (couleurs mixtes), overlay, boutons, affichage IP serveur
- **Sections** : Activer/désactiver chaque section, définir l'ordre, personnaliser titres/sous-titres
- **Footer** : Description, liens sociaux (Discord, Twitter, YouTube, Instagram, TikTok, GitHub, Twitch), liens légaux
- **Avancé** : Injection de CSS, JS et code head personnalisés

### Installation

1. Téléchargez le dossier `recraft`.
2. Uploadez-le dans le répertoire `themes/` de votre installation Azuriom.
3. Allez dans Panneau Admin -> Apparence -> Thèmes.
4. Activez **ReCraft**.
5. Configurez le thème depuis le panneau de paramètres.

### Prérequis
- Azuriom API 1.2.0+
